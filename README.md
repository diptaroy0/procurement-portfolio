## 📌 About

This repository contains my professional portfolio website, developed to showcase my experience in **Procurement, Supply Chain Management, Strategic Sourcing, Supplier Development, Industrial Automation, and Engineering Projects**.

The portfolio highlights my professional journey, technical expertise, procurement workflow, case studies, achievements, and career progression through an interactive and responsive web application.

## 🎯 Why This Portfolio?

I developed this portfolio to present my professional experience in Procurement & Supply Chain Management through an interactive and modern web application. Beyond showcasing my career, it demonstrates my ability to organize information, solve problems systematically, and leverage modern technologies to communicate professional value effectively.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/diptaroy0/procurement-portfolio.git
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
